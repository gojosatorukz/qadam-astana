# Qadam v4: сценарии проверки

## Автоматический запуск

```sh
npm ci
npx tsc --noEmit --incremental false
node --experimental-strip-types --test tests/*.test.ts
```

На отдельной чистой установке 20 октября 2026: TypeScript pass, **167/167 тестов**, no-key HTTP smoke **8/8**. В тестовый итог входят прежние 21 сценарий на сохранённых OSM POI/графе,30 oracle integration и unit/mocked-provider проверки. Oracle не вызывает модель и не измеряет AI accuracy. [Метод и фактические выходы](EVALUATION.md).

| Проверка | Ожидаемый результат |
|---|---|
| Пустой query, ручные категории, ключа нет | `manual`, план по явным кнопкам; интерпретатор не вызывает сеть |
| Непустой query, ключа нет / timeout / provider error | `needs-clarification`, plan=null; default chips не подменяют текст |
| «Музей» при исходной coffee-кнопке | При валидном intent только музейные категории; текст авторитетен |
| Запреты в intent, в том числе secondary tags | Запрещённый POI не попадает в кандидаты/план |
| RU/EN/KK простые negative lists и вставки | Legacy helper исключает поддерживаемые формы; API не использует его как скрытый semantic fallback |
| `all` / `any` | `all` стремится покрыть разные нужные категории; `any` допускает любой вариант; недоступное явно отражено в feedback |
| Категория + «тихо, недорого, Wi-Fi» без подтверждения | Цитаты no-data отдельно, статус partial; свойства не заявляются как факты |
| Неизвестный смысл или конфликт с переключателем | Уточнение; запрос не меняет контрол самовольно |
| Недостаточно времени на посещение и возврат | `plan=null`; маршрут не выдумывается |
| Успешный маршрут | 1–3 исходных POI; `total=walking+visit+buffer≤budget`; `walking=transitions+return` |
| Нет часов / неподдерживаемый формат | unknown; knownHoursOnly исключает запись |
| Секунды у границы закрытия, overnight, off | Весь визит проверяется в Asia/Almaty |
| `now` без timezone | HTTP 400; разрешены ISO с Z или явным ±HH:MM |
| Indoor / wheelchair неизвестны | Требуются true и yes/designated соответственно |
| U-образный граф и слишком длинный return | Реальный network cost до выбора, не короткая линия по прямой |
| Нет покрытия / разрыв сети | estimate с предупреждением; известный длинный путь не подменяется fallback |
| Соединение с графом до 200 м | Длина включена, препятствия не подтверждены |
| Выбор трёх остановок | Не более четырёх деревьев Dijkstra; эвристика не объявляется глобальным оптимумом |
| Generation меняет ID, порядок, схему или даёт free prose | Ответ отклонён, исходный план сохранён |
| Корректные summaryKey/reasonKeys/activityKey | Проверяются per-stop разрешения; текст выводится локально на RU/KK/EN |
| listed-hours для unknown / category-match без intent | Код не разрешён, grounding failure |
| Второй этап HTTP 503 / timeout / invalid output | Bounded retry только где разрешён, общий deadline; проверенный план остаётся retrieval |
| Fetch или body reader игнорирует AbortSignal | Promise.race ограничивает ожидание; новый этап не получает полный новый deadline |
| Ошибки / чувствительные provider bodies | Пользователю не возвращаются ключи, provider body или stack |

## Ручной прогон интерфейса

Это план проверки, а не утверждение, что каждый браузерный шаг уже автоматически выполнен.

| Действие | Проверить |
|---|---|
| Пустой текст, набережная, кофе 45, известные часы | Реальный источник, возврат, запас; на фиксированном снимке 39 минут |
| Те же условия, 20 минут | Честный empty |
| Семантический «музей, без кафе» при рабочем провайдере | Видимый intent, запрет и фактический matched/partial/empty; default coffee не возвращается |
| Неподтверждаемые quiet/cheap/Wi-Fi | Видимые цитаты unknown; UI не обещает эти удобства |
| Нет ключа или ошибка интерпретации | Уточнение; кнопка явного ручного режима очищает текст и использует выбранные категории |
| All-категории не помещаются | Partial с недостигнутыми категориями, без ослабления бюджета/часов |
| Будущее отправление | Абсолютная дата стабильна после полуночи, часы относятся к выбранной дате |
| Источник | OSM-ссылка, исходные поля, unknown и дата снимка |
| RU/KK/EN | Видимые labels, даты, состояния и новое объяснение локализованы; собственные имена источника могут оставаться исходными |
| Mobile / клавиатура / диалог | Видимые focus и labels, Escape/close, кнопки не перекрыты; нет горизонтального скролла |
| Отказ геолокации | Понятная ошибка; публичные preset-старты продолжают работать |
| Нет тайлов OSM | Сообщение о подложке; сохранённые точки и расчёт доступны |

Health `geminiConfigured=true` означает наличие конфигурации, не успешный ответ модели. В POST проверяйте отдельно `intent.mode` и `generationMode`: ручная интерпретация может иметь Gemini-объяснение, семантический intent может сохранить retrieval-объяснение. Не показывайте ключи и личную точную геолокацию в видео.
