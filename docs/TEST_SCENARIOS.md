# Сценарии проверки Qadam

## Автоматические проверки

```sh
npx tsc --noEmit --incremental false
node --experimental-strip-types --test tests/planner.test.ts tests/extended.test.ts
```

Прогон 19 октября 2026 года: TypeScript без ошибок; **61 тест прошёл, 0 ошибок**: 38 unit и 23 extended. Unit-набор использует контролируемые POI, синтетический граф и подменённые ответы Gemini. Extended-набор содержит 21 сценарий на реальном снимке, provenance и повторяемость. Ключ и внешний API не нужны. [Фактические выходы и ограничения](EVALUATION.md).

| Условие | Ожидаемый результат |
|---|---|
| Недостаточно времени на визит и возврат | `plan=null`, выполнимый маршрут не выдумывается |
| Успешный план | `total = walking + visit + buffer`; возврат включён; итог ≤ бюджета |
| Нет часов или неподдерживаемый формат | `hoursStatus=unknown`; строгий фильтр исключает запись |
| Закрытие до конца посещения | Место исключается даже без фильтра известных часов |
| Будни, выходные, ночной интервал, `off` | Проверка в `Asia/Almaty` на всё время посещения |
| Indoor / wheelchair неизвестны | Indoor требует `true`; wheelchair — `yes` или `designated`; `limited` не принимается |
| Запросы кофе / музей / саябақ | Категории распознаются на RU/EN/KK; `small` и `start` не становятся mall/art |
| Нет подходящих POI | Полезный пустой результат без выдуманного места |
| Дубли, неверные координаты, нет источника | Записи исключаются |
| Много кафе, есть другие категории | До трёх разных POI; нет искусственного маршрута по трём кафе; сохраняется разнообразие retrieval |
| U-образный граф с обходом | Кратчайший взвешенный путь содержит промежуточные вершины и возврат |
| По прямой близко, по графу долго | Известный слишком длинный путь не заменяется коротким fallback |
| Нет покрытия в пределах 200 м / связного пути | `routeKind=estimate`, предупреждение о покрытии |
| Соединение координаты с узлом | Длина включена; препятствия на соединении обозначены как непроверенные |
| Wheelchair и stair-edge | Лестницы исключаются; разрыв не выдаётся за доступный сетевой маршрут |
| Несколько остановок | Деревья Dijkstra переиспользуются; не более четырёх источников поиска на сессию |
| Gemini меняет ID, порядок, дублирует POI | Ответ отклонён; детерминированный план сохранён |
| Корректный ответ Gemini | Меняются только summary/why/activity; время, POI и геометрия сохранены |
| HTTP 503 / настроенная запасная модель / таймаут | Ограниченный retry или явный model fallback; далее честный `retrieval` |
| Не-JSON / ошибка grounding-проверки | Немедленный retrieval-fallback; не повторяется как временный сбой провайдера |
| Запрос вне города, неверные типы, большие размеры | Валидация отклоняет вход; ошибки не раскрывают ключ/тело ошибки провайдера |

Эти тесты не доказывают актуальность OSM, безопасность улиц, реальную доступность помещений или истинность каждой фразы LLM.

## Ручной прогон интерфейса

Таблица задаёт ожидаемые результаты; это **не журнал завершённых E2E-проверок**. Конкретные места и формулировки зависят от времени и модели: проверять инварианты.

| Действие | Проверить |
|---|---|
| «Пауза между парами» | Байтерек, 35 минут, кафе; реальные POI, возврат и запас |
| «Новый взгляд на EXPO» | EXPO, 60 минут, достопримечательности; карта соответствует ответу API |
| Уменьшить время до 20 минут | Новый план помещается в бюджет либо становится пустым |
| Открыть источник места | Правильная OSM-ссылка, исходные поля, unknown, дата снимка |
| Включить известное расписание | Только распознанные часы, открыто на весь визит; пустая выдача допустима |
| Включить indoor / wheelchair | Неподтверждённые записи исключены; понятный empty-state |
| Переключить RU / KK / EN и построить заново | UI и новые объяснения на выбранном языке; имена POI могут оставаться на языке источника |
| Отказать в геолокации | Понятная ошибка; готовые стартовые точки работают |
| Запуск без Gemini-ключа | Подбор работает, виден retrieval; генерация не имитируется |
| Заблокировать тайлы OSM в DevTools | Сообщение о подложке; точки и расчёт по сохранённым данным работают |

Live-smoke: проверить `GET /api/plan` и реальный `POST /api/plan`. `geminiConfigured` означает наличие конфигурации; только успешный POST с `generationMode=gemini` подтверждает генерацию для конкретного запроса. Не показывать секреты и точную домашнюю геолокацию в записи.
