# Qadam VNext: сценарии и порядок проверки

## Автоматический набор

```sh
npm ci
npx tsc --noEmit --incremental false
node --experimental-strip-types --test tests/*.test.ts
node --experimental-strip-types scripts/import-place-facts.mjs --check
```

Записывайте итог и версию source в финальный release log после freeze. Число тестов в ходе работы меняется. Браузерные сценарии и реальные вызовы провайдера не прибавляются к unit-итогу. Importer использует публичные review-входы в `scripts/place-facts-evidence`; для запуска не нужен соседний private/research-каталог.

Существующие 21 сценарий на реальном OSM snapshot и 30 oracle integration остаются отдельными группами. Oracle подаёт заранее заданный intent и проверяет pipeline; он не измеряет AI accuracy. Frozen intent gold и результаты исторического сетевого прогона не переписываются. [Методика](EVALUATION.md).

| Проверка | Инвариант |
|---|---|
| 31.02, невисокосное 29.02, 24:00, отсутствующий timezone | Не нормализуются в другую дату; ошибка валидации |
| 29.02 високосного года и UTC+5 через полночь | Настоящий instant; одинаковый результат независимо от timezone устройства |
| Прошлое custom-отправление | Отклоняется; исторические fixtures без custom mode не запрещаются |
| Сейчас + returnBy, интерпретация занимает время | Остаток считается заново после неё, округляется вниз; departureAt/effectiveMinutes отражают расчёт |
| Дедлайн или custom departure устаревают во время интерпретации | plan=null, typed stale-time; прежний выполнимый план не возвращается |
| Mega в тексте, Байтерек в настройках | Вопрос с двумя явными действиями до вызова AI; input не мутирует |
| Подтверждение «оставить старт» или «Mega» | Новая точка применяется только по действию; query/time/фильтры сохраняются |
| Свободное уточнение «нет, лучше парк» после футбола | Старый activity preflight не зацикливается; полная история и запреты остаются у интерпретатора |
| Новый названный старт в свободном ответе | Проверяется последний контекст, а не повторяется старый Mega |
| Непустой текст без ключа/при timeout/429/invalid shape | Нет guessed route; полезное уточнение и ручные действия |
| Явное ручное восстановление localOnly | Оба provider function не вызываются; query пустой, выбранная категория и hard filters применены |
| Кофе + неизвестная тишина/цена/Wi-Fi | partial/no-data; supported activity не требует лишнего подтверждения unknown-факта |
| Футбол, shopping, отдельный gallery-запрос | Честная граница данных, полезные явные действия; без fake cafe/sports/shop category |
| Запрет категории, включая secondary source tags | Ни один вариант не содержит запрещённый POI |
| all / any | all стремится покрыть категории, не ослабляя бюджет/часы; partial честно виден |
| unknown/сложные часы, граница с секундами, overnight/off | Весь визит в Asia/Almaty; unknown не превращается в open |
| Indoor/wheelchair не подтверждены | Строгие фильтры исключают запись |
| Любой показанный вариант | 1–3 исходных POI; total=walking+visit+buffer≤effective budget; walking=переходы+return |
| Два варианта | Разные canonical sets, измеримый tradeoff, одинаковые фильтры и отдельная полная проверка |
| Source ranking | При выполнимом named/curated варианте не предпочитать безымянный только за близость; closed/неподтверждённые/слишком длинные богатые записи не возвращаются; all coverage важнее richness |
| Канонические node/way aliases | Не становятся двумя остановками/«разными» вариантами; случайная близость не объединяется |
| Вариантов нет или один | Честное empty/один; перестановки и одинаковые затраты не создают второй ради числа |
| Два графовых варианта | Общая граница до четырёх Dijkstra; возврат и connectors учтены до выбора |
| Слишком длинный известный сетевой путь | Не подменяется короткой прямой оценкой |
| Нет покрытия сети | Явный estimate и предупреждение; граница POI не обещает связность |
| Подмена ID/порядка/кодов/free prose при объяснении | Ответ отклонён; локальный расчёт сохраняется |
| Ошибка второго этапа | План сохранён; enrichment unavailable отдельно от not-attempted |
| Parent abort до/во время intent, body parsing, enrichment | AbortError распространяется; следующий этап не начинается; нет ложного success |
| Renderer мутирует вход или возвращает плохой shape/semantics | Не меняет исходные POI, ограничения и маршрутные факты |
| Факт и source alias | Разрешённый ID, HTTPS source URL, checkedAt/rights; overlay не меняет фильтры и геометрию |
| Пустой корпус или нет выполнимого плана | Диагностика planning; AI enrichment не объявляется вызванным/сбойным |

## Направленный ручной smoke

Таблица ниже задаёт ожидаемое поведение. Факт выполнения, браузер, viewport, время, source SHA и evidence записываются отдельно в протокол VNext QA. Она не объявляет каждый шаг уже пройденным.

| Действие | Проверить |
|---|---|
| Байтерек, «парк возле Mega, старт от Mega» | До loading AI виден осмысленный выбор; подтверждение сохраняет желание/время/фильтры |
| Модель недоступна → ручная категория | Рабочий локальный результат без повторного обязательного AI; факт ручного выбора виден |
| Музей, старт у Национального музея, будущий день | Читаемое canonical name; факт с source/checkedAt; observation отдельно как идея; без двух музейных aliases |
| Своя дата, длительность | Дата остаётся абсолютной; timezone Алматы; после полуночи label не съезжает |
| Своя дата и returnBy на следующую дату | Обе даты и актуальный лимит видны, return+buffer включены |
| Сейчас + returnBy, затем ожидание/редактирование | Stale state предлагает пересчёт, новый дедлайн инвалидирует старый ответ |
| Одно/два доступных решения | Выбор меняет карточки и полную геометрию; tradeoff числовой; не обещать два всегда |
| «Футбол» / shopping | Релевантная граница корпуса и внешний поиск только по клику; query не заменён кафе |
| Футбол → свой ответ «Нет, лучше парк» | Полезное продолжение, без повторного неподходящего вопроса |
| Local POI search / отдельный pin mode | Нет скрытого перемещения старта при обычном drag; явно выбранная точка подтверждается |
| Pin за snapshot rectangle | Предложение изученного района; запрос/время сохранены; rectangle не означает walking coverage |
| Все точки/изломы маршрута и resize/mobile | Fit учитывает полную геометрию; выбор/карта связаны, нет горизонтального overflow |
| Изменение бюджета/старта во время запроса | Старый ответ не появляется под новыми controls; запрос отменён/инвалидирован |
| Недоступны тайлы / отказ GPS | List/manual presets работают, состояние сети понятно |
| RU/KK/EN | Questions, options, даты/ошибки/факты читаемы и локализованы |
| Keyboard/native dialog/Escape/mobile390×844/reduced motion | Focus/close/CTA доступны; CSS и JS smooth не навязываются |
| Favorites сохранить/удалить/очистить/storage error | Только публичные POI IDs; запросы/маршруты/точная история не записаны |
| Внешние ссылки | HTTPS, ожидаемый сервис, нет активных схем/credentials; переход только по действию |

Матрица аудита содержит 34 пункта с разными статусами offline/live/notchecked; её нельзя представлять как 34 новых успешных UI-теста. Наблюдение за добровольными людьми — отдельная пользовательская проверка; агенты, тесты и browser smoke её не заменяют.

Health `geminiConfigured=true` подтверждает конфигурацию, не успешность модели. `intent.mode`, `generationMode`, `diagnostics.intent/enrichment/coverage` отражают разные стадии. Generation mode относится к primary; alternative-local-explanation указан в trace. Не показывайте ключи, личный query или точную частную геолокацию в видео.
