# Qadam — короткая прогулка по Астане

Qadam подбирает 1–3 реальных места под интересы и свободное время. План включает переходы, посещение, возвращение к старту и запас. Источники и неизвестные сведения доступны в карточке; предлагаемые занятия отделены от фактов.

**[Открыть публичное демо](https://qadam-astana-walk.pubg-bekzat.chatgpt.site)** · **[Видео демонстрации](https://youtu.be/li0ZsXU8YvU)** · [Исходный код](https://github.com/gojosatorukz/qadam-astana) · [Результаты проверки](docs/EVALUATION.md) · [Ответы жюри](docs/JURY_QA.md)

Проект команды **Qadam** для кейса Smart City «ИИ-помощник по прогулкам в городе Астана». [Хакатон](https://gdg.community.dev/events/details/google-gdg-astana-presents-build-with-ai-hackathon-2026/).

## Запуск

Нужны Node.js ≥22.13 и npm.

```sh
npm ci
npm run dev
```

Откройте адрес из вывода сервера; локально обычно `http://localhost:5173`. Стек: React, TypeScript, Vinext/Vite, серверный API для Cloudflare Workers.

Для AI-объяснений передайте серверу `GEMINI_API_KEY` через окружение или `.env.local`; `.env*` исключены из Git. Модель по умолчанию — `gemini-3.5-flash-lite`, настройка — `GEMINI_MODEL`. Дополнительные проверенные модели можно явно перечислить в `GEMINI_FALLBACK_MODELS`. Без ключа или при сбое провайдера работает явно обозначенный режим `retrieval`.

Файл [.env.example](.env.example) содержит только пустой шаблон: скопируйте его в `.env.local` и добавьте собственный ключ. Не передавайте ключ браузеру и не публикуйте `.env.local`.

## Реализовано

- RU / KK / EN, четыре стартовые точки, геолокация по запросу, два готовых сценария.
- Отправление «Сейчас» или «Завтра, 12:00» с явно отображённой датой; расписания проверяются для выбранного момента.
- Интересы, текст запроса, бюджет времени; строгие фильтры indoor, расписания и wheelchair по данным источника.
- Retrieval по категориям, словам и тегам; разнообразный shortlist до 18 кандидатов; до трёх остановок разных категорий.
- Простые отрицания RU / EN / KK: например, «без кафе, только парк». Сложная логика запросов не заявляется.
- Dijkstra по графу OSM. При отсутствии покрытия — обозначенная геометрическая оценка. Известный слишком длинный сетевой путь не подменяется короткой оценкой.
- Проверка расписания на всё посещение в `Asia/Almaty`; неподдерживаемый формат остаётся `unknown`.
- Gemini объясняет уже выбранный план. Проверка ID, порядка и формата; модель не изменяет POI, время и геометрию.
- Карта на тайлах OSM, источники, trace расчёта, честный fallback и пустой результат.

Свободный текст помогает поиску, но произвольные сложные ограничения и отрицания не интерпретируются универсально. Поддерживаемые строгие условия задаются переключателями. [Архитектура и границы](docs/DECISIONS.md).

## Данные

Снимок от 19 октября 2026 года, центральная Астана: EXPO, Байтерек, Национальный музей, набережная. Это не весь город и не live-каталог.

| Показатель | Количество |
|---|---:|
| POI / с названием в источнике | 890 / 421 |
| С `opening_hours` / wheelchair-тегом | 116 / 40 |
| Явное `indoor=yes` | 8 |
| Узлы / рёбра графа | 81 383 / 97 427 |

```sh
node scripts/collect-pois.mjs              # POI и provenance
node scripts/collect-pois.mjs --graph-only # граф
node scripts/collect-pois.mjs --graph      # оба набора
```

Автосбор через публичный Overpass API сохраняет исходные теги, удаляет близкие дубли с одинаковыми именем и категорией. Описания — шаблон из фактов источника; истории, цены и рейтинги не выдумываются. Запросы, timestamp, SHA256, статистика и правила — в `data/provenance.json`; граф содержит собственные метаданные. Обновление запускается командой, фоновой синхронизации нет. Ошибка загрузки не заменяет сохранённый набор пустыми данными.

Данные: © OpenStreetMap contributors, [ODbL](https://www.openstreetmap.org/copyright). Тайлы загружаются отдельно от сохранённых POI и графа.

## Проверка

```sh
npx tsc --noEmit --incremental false
node --experimental-strip-types --test tests/planner.test.ts tests/extended.test.ts
```

Проверка 19 октября: TypeScript без ошибок, **61/61 тестов** — 38 unit и 23 extended. Extended-набор включает 21 сценарий на реальных POI и пешеходном графе, provenance и повторяемость. Проверены обратный путь, бюджет, часы, отсутствие результатов, grounding ID, отрицания и граница закрытия с секундами. Это не процент релевантности или оценка точности по всему городу. [Полный отчёт](docs/EVALUATION.md) · [Сценарии](docs/TEST_SCENARIOS.md).

Надёжный сценарий ночной проверки: **Набережная Есиля → кофе → 45 минут → с известным расписанием → Сейчас**. На текущем снимке выбран Coffee Original (`24/7` в OSM): 39 минут, включая 5 минут обратно и 4 минуты запаса. При 20 минутах выдача пуста. Указанные часы остаются сведениями источника, не подтверждением фактического открытия двери.

## Ограничения и приватность

OSM может быть неполным или устаревшим. У 774 POI нет расписания, у 882 indoor неизвестен. Все восемь явных indoor-записей — детские площадки. Строгие фильтры могут вернуть пустую выдачу. Wheelchair-тег и исключение лестниц не подтверждают доступность всего пути.

Время оценено при 4,2 км/ч. Соединения с ближайшим узлом до 200 м идут по прямой; входы и препятствия не проверены. Геометрический fallback использует расстояние по прямой ×1,35. Это прототип планирования, не официальная навигация.

Код не сохраняет историю координат, запросы и планы в БД или browser storage. Точный старт передаётся серверу для текущего расчёта. Хостинг/Cloudflare обрабатывает запросы и сетевые метаданные; OSM получает запросы тайлов выбранной области. Gemini получает query, язык и выбранные POI, без отдельного поля точного старта и его координат. Если пользователь сам впишет личные сведения или координаты в query, они попадут в этот текст. Политики и журналы внешних провайдеров приложение не контролирует.
