# Qadam — куда успеть по пути между делами

Qadam помогает выбрать, куда зайти в Астане между делами. Пользователь задаёт точку А, доступное время и, по желанию, точку Б. Приложение предлагает до четырёх выполнимых вариантов по 1–3 реальных места: дорога, посещения, путь до цели или обратно и запас уже входят в бюджет. Можно написать «покушать» или оставить желание пустым для автоматического выбора поблизости.

## Запуск

Нужны Node.js ≥22.13 и npm. В публичном репозитории полный код находится в [qadam-source.zip](https://github.com/gojosatorukz/qadam-astana/blob/main/qadam-source.zip). Проверяйте его точный source commit и SHA256 по [source-manifest.json](https://github.com/gojosatorukz/qadam-astana/blob/main/source-manifest.json): выпуски и запись основного сценария имеют собственные версии; актуальный commit берите из manifest. Для полученных исходников:

```sh
npm ci
npm run dev
```

Откройте адрес из вывода сервера, обычно `http://localhost:5173`. React, TypeScript, Vinext/Vite; серверные API исполняются на Cloudflare Workers.

Для понимания текстовых запросов задайте серверный `GEMINI_API_KEY` через окружение или `.env.local`. `.env.example` в архиве содержит пустой шаблон. Модель по умолчанию — `gemini-3.5-flash-lite`; настройка — `GEMINI_MODEL`. Дополнительные проверенные модели объяснения задаются через `GEMINI_FALLBACK_MODELS`. Ключ не попадает в frontend, Git или архив.

## Открытие места в 2ГИС

В карточках, источниках и избранном есть открытие публичной точки места в 2ГИС, рядом остаётся Google Maps. Для футбола и shopping первый внешний поиск тоже ведёт в 2ГИС. Переход происходит только по нажатию: Qadam не передаёт старт пользователя, историю или полный текст запроса в ссылке точки. Ссылка «Точка на карте 2ГИС» использует документированный формат `/geo/долгота,широта`, с координатами публичной точки и масштабом карты. 2ГИС сам выбирает карточку покрывающего или соседнего объекта; это не проверенный ID организации, вход или совпадение маршрутов. Приложение не импортирует сведения 2ГИС и не использует его API/SDK.

OpenStreetMap не назван обязательным провайдером в официальном Smart City-кейсе. В проекте он остаётся источником собранного снимка и пешеходного графа, с атрибуцией ODbL. Открытие в другом сервисе не меняет происхождение данных или расчёт времени Qadam.

## Выбор и уточнение

- Старт А можно выбрать из четырёх районов, найти среди названных POI снимка, поставить на полноэкранной карте или получить GPS по нажатию. Нажатия по свободной карте меняют pin, а подтверждение применяет точку. Карта результата также раскрывается на весь экран. Произвольный внешний geocoder не используется.
- По умолчанию выбран круговой маршрут. Необязательная точка Б переключает расчёт на А → остановки → Б; её можно выбрать тем же поиском или на карте. Без Б последняя часть ведёт обратно в А. Пустое желание допустимо: приложение ищет подходящие места по точкам, времени и фильтрам.
- «Покушать», «поесть», «обед», «тамақ ішу» и meal-запросы имеют отдельную категорию `food`: рестораны, fast food и food court из OSM. Обычный запрос еды не требует повторно выбирать занятие. Посещение еды занимает минимум 20, предпочтительно 35 минут; меню, цены и диетические свойства не выдумываются.
- При конфликте «старт от Mega» с выбранным Байтереком приложение предлагает подтвердить одну из точек. Текст не переносит старт самовольно; точка района не выдаётся за проверенный вход. Для явно названного незнакомого старта предлагается поиск/карта или явное сохранение текущего старта; подтверждённая точка не вызывает повторного того же вопроса.
- Уточнение содержит вопрос и 2–4 действия: ручная категория, подтверждение старта, повтор, редактирование или явный внешний поиск. Свой ответ добавляется к видимому диалогу и снова проходит интерпретатор. Общий лимит — 4000 символов, один ответ — 500; переполнение объясняется до запроса, предыдущий текст не обрезается. HTTP-лимит — 32 КиБ. Явно заменённое занятие не должно оставаться невыполненным желанием; неотозванные запреты сохраняются.
- Нет ключа, timeout или ошибочный intent — семантический запрос требует уточнения. Явный ручной выбор очищает текст, передаёт `localOnly=true` и работает без **обоих** вызовов AI, сохраняя старт, время и переключатели.
- Понятная категория с неподтверждаемой тишиной, ценой или Wi-Fi может дать `partial`, без лишнего подтверждения неизвестных свойств. Они не становятся фактами места.
- Футбол, матчи и shopping не подменяются кафе: таких данных нет. Qadam показывает границу корпуса и предлагает внешний поиск только по нажатию. Уличное искусство не подтверждает наличие галереи.

Время задаётся как длительность или «вернуться к», с произвольной будущей датой и временем **Алматы (UTC+5)**. Сервер проверяет календарь, високосные годы и явный timezone. Для режима «Сейчас» остаток до `returnBy` пересчитывается после интерпретации; ответ содержит абсолютные `departureAt`, `planComputedAt`, `returnBy` и `effectiveMinutes`. После второго AI-этапа время и выполнимость каждого варианта проверяются ещё раз без нового model call. Истёкший custom departure не остаётся активным планом в интерфейсе; желание, старт и фильтры сохраняются для нового времени.

Каждый вариант включает все переходы, посещения, последний участок до Б (либо возврат в А) и запас. До четырёх вариантов имеют разные канонические места и проверяются независимо; одинаковые фильтры и бюджет действуют на все. Дополнительные варианты не добавляют Dijkstra-поисков. Если на остановку времени нет, отдельный прямой путь А→Б показывает время и минимум с запасом; он не выдаётся за найденное заведение. Доказанно несвязные А/Б или известный слишком длинный сетевой путь не подменяются короткой оценкой по прямой.

## AI и источники

Gemini переводит текст в закрытый intent: девять категорий, желаемые и запрещённые категории, `all/any`, цитаты неизвестных пожеланий и флаг уточнения. Код применяет исключения, indoor, расписание, wheelchair и считает маршрут. Retrieval использует категории, географию и слова корпуса; embeddings и векторной БД нет. В production при сопоставимом покрытии предпочитаются проверенные факты и исходные имена OSM перед безымянными объектами. Небольшой bounded bonus не ослабляет фильтры/бюджет и не является оценкой качества места.

Необязательный второй вызов выбирает только допустимые `reasonKeys`, `activityKey`, `summaryKey` для **основного** маршрута. Приложение выводит RU/KK/EN-текст локально. Остальные варианты получают локальные объяснения из источников, без дополнительного AI-вызова. `generationMode` относится к основному объяснению; trace и diagnostics отмечают локальные объяснения альтернатив. При сбое второго этапа проверенный план сохраняется. Ручное восстановление `localOnly` полностью локально.

Дополнительный редакционный слой содержит **10 канонических мест, 11 явных OSM-ID, 18 фактов из 5 URL и 4 идеи наблюдения**. Факты имеют URL, дату проверки источника и rights. Идея наблюдения показана отдельно от факта. Дата проверки веб-источника не означает полевую проверку места, входа или текущего режима работы. Алиасы объединяются только по проверенному соответствию; близость координат сама по себе не является доказательством.

## Корпус и маршрут

Сохранённый снимок центральной Астаны, расширенный заведениями еды 20 октября 2026, покрывает районы EXPO, Байтерека, Национального музея и набережной. Это не live-каталог всего города.

| Показатель | Количество |
|---|---:|
| Записи OSM / с собственным названием | 1204 / 713 |
| Со строкой `opening_hours` / wheelchair-тегом | 250 / 53 |
| Явное `indoor=yes` / `wheelchair=yes,designated` | 8 / 31 |
| Добавленные food / сохранённые исходные записи | 314 / 890 |
| Узлы / рёбра графа | 81 383 / 97 427 |

```sh
node scripts/collect-pois.mjs              # POI и provenance
node scripts/collect-pois.mjs --graph-only # граф
node scripts/collect-pois.mjs --graph      # оба набора
```

Все 890 исходных записей и их порядок сохранены без изменений; отдельный hash-инвариант проверяется тестом. Добавлены 314 source-bound записей: 177 ресторанов, 135 fast food и 2 food court. Overpass-сбор сохраняет исходные теги, URL, timestamp и SHA256 в `data/provenance.json`. Фоновой синхронизации нет. Данные: © OpenStreetMap contributors, [ODbL](https://www.openstreetmap.org/copyright). Редакционные факты хранятся отдельно в `data/place-facts.json` и не изменяют routing/filter-поля OSM.

Графовый выбор — ограниченная эвристика, до пяти деревьев Dijkstra суммарно на запрос со всеми вариантами: А, Б и не более трёх источников выбранных остановок; глобальный оптимум не заявляется. Скорость — 4,2 км/ч. Соединения до графа ≤200 м оценены по прямой и не проверены на препятствия. Если покрытия нет, используется явно обозначенная оценка «прямая ×1,35». Известный длинный путь не заменяется короткой оценкой ради результата. Граница снимка POI не гарантирует связность сети.

Неизвестные/сложные часы остаются `unknown`; `knownHoursOnly` требует расписания на **весь** визит. Это не проверка открытой двери. Indoor требует явного true, wheelchair — yes/designated; исключение лестниц не сертифицирует доступность всего пути. Реальное время и безопасность переходов не гарантируются.

## Быстрый smoke

На телефоне сначала откройте picker, дважды нажмите на разные свободные участки полноэкранной карты и подтвердите pin; затем откройте полную карту результата. Для еды: «покушать», А=Байтерек, необязательная Б=Национальный музей, 90 минут; проверьте несколько вариантов, путь до Б и полный бюджет. Конкретные названия зависят от даты и фильтров.

Проводите на выбранной будущей дате, не выдавая её за текущее посещение.

1. Оставьте старт «Байтерек», введите «Хочу погулять в парке возле Mega Silk Way, старт от Mega». Должен появиться явный выбор точки до AI. Подтвердите Mega; без ключа продолжите через ручной выбор парка.
2. Без ключа выберите вручную музей, старт «Национальный музей», будущую дату днём и достаточное время. Откройте карточку источников: каноническое имя, содержательный факт с URL и отдельная идея. Не включайте indoor без подтверждённых данных.
3. Выберите своё время выхода и «вернуться к» с полной датой. Проверьте показанные дату, бюджет, обратный путь и запас. Измените дедлайн — старый результат не должен остаться актуальным.
4. Введите «Хочу поиграть в футбол». Ожидается честное объяснение отсутствующих данных и явный переход к поиску площадок/матчей, без автоматического маршрута по кафе. Новый ответ «Нет, лучше парк» должен продолжить диалог.

## Проверка и выпуск

Текущий направленный QA проверил с настоящим Gemini: «покушать» при круговом окне 45 минут даёт четыре food-варианта; при А=Байтерек, Б=Национальный музей и 90 мин — четыре food-варианта, каждый доходит до Б в лимите. Один основной результат: 90 = 53 ходьба + 29 посещение + 8 запас. Это командный smoke, не пользовательский пилот и не измеренная точность модели. Desktop-эмуляция проверяет мобильный layout, free pin и полную карту; физические iPhone, жесты multi-touch и открытие нативного 2ГИС остаются отдельной проверкой.

Приложение не хранит историю запросов или координат в БД/browser storage. По явному действию в браузере сохраняются только ID выбранных публичных мест; их можно очистить. Структурированные координаты и время не передаются в intent payload, но введённые в query адреса/личные сведения могут попасть модели. OSM получает запросы тайлов области; технические журналы внешних сервисов приложение не контролирует.

Две проверенные фотографии Ботанического сада и парка Жетысу хранятся отдельно в `data/place-photos.json`: автор, источник Wikimedia Commons, год съёмки, CC BY-SA 4.0 и точное соответствие POI видны пользователю. Это архивные фото, не live-вид. Проверенных фотографий ресторанов пока нет; чужое место или AI-картинка вместо него не подставляются. Google Places/2ГИС photo API не подключены.
