Qadam: карточка репетиции перед защитой

План выступления: 6:10. Это целевой тайминг, а не проведённая репетиция.
Не включать целиком 90-секундное видео внутри этой речи: оно увеличит общий хронометраж.
Видео служит отдельным материалом заявки и резервом для демонстрации.
Если показываешь живой интерфейс, говори поверх действий. При ожидании API продолжай объяснение.

0:00–0:20 / Слайд 1. Один человек у Байтерека. До следующей встречи 90 минут.
  Опорная фраза: «Хочется выйти, заметить новое и успеть обратно».
0:20–0:55 / Слайд 2. Парк, без кафе. Свой старт. 12:15–13:45.
  Покажи желание и срок. Перечень всех элементов интерфейса можно пропустить.
0:55–1:40 / Слайд 3. 85 или 55. Выбор действительно разных мест.
  Покажи компромисс: 52 или 22 минуты ходьбы. Финальный выбор остаётся человеку.
1:40–2:20 / Слайд 4. Одна деталь, ради которой хочется выйти.
  Скульптура: отдельный факт со ссылкой. Рассмотреть фигуры: условная авторская идея.
2:20–2:55 / Слайд 5. Встречу перенесли раньше. 90 стали 45.
  Сохранились желание, старт, запрет кафе. Дальний парк не помещается, ближний сквер укладывается.
  Числа: 22 пути + 19 посещения + 4 запаса. Это оценка. 2ГИС открывает точку, вход надо проверить.
2:55–3:35 / Слайд 6. Отдельный случай: «старт от Mega» при Байтереке в настройках.
  Система спрашивает, человек подтверждает. Главный маршрут уже объяснён.
3:35–4:15 / Слайд 7. Речь разбирает Gemini, выполнимость проверяет код, факты имеют источники.
  Не обещай, что LLM считает минуты или получает все 18 исторических фактов как RAG snippets.
4:15–5:05 / Слайд 8. Автосбор, проверки, реальный запрос, пределы.
  Число тестов кода не равно точности языковой модели. Каталог 890, но расписания есть у 116.
5:05–5:50 / Слайд 9. Кто использует, кто обновляет, как проверить пользу.
  Пять наблюдений ещё не проведены. Партнёрств, продаж и пилота не заявляй.
5:50–6:10 / Слайд 10. Вернись к человеку. Предложи проверить свой сценарий по QR.
  Заверши одной фразой: «У короткой паузы появился понятный выбор».

Порядок собственной репетиции
1. Один прогон с секундомером без правки по пути. Запиши реальное время.
2. Если выходит больше 7 минут, сократи слова, а не ускоряй речь.
3. Второй прогон по этой карточке, без чтения полной речи.
4. Проверь открытие QR, видео и субтитров. Держи PDF и MP4 локально как резерв.
5. Если live API недоступен, назови резерв записью реального прототипа. Не играй её как живой запрос.

Слайды дополняют голос: крупные числа показывают компромисс, скриншоты подтверждают результат.
Условия исполнения маршрута, реальные входы и пользовательский эффект ещё нужно проверить на месте.
